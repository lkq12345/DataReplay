# 开发约定

本文档记录 DataReplay 项目的开发约定，项目参与者（含 AI 辅助开发）均应遵守。

## Git 提交与推送

1. **推送前必须经用户允许**：任何涉及 `git push`（向远程仓库推送代码）的操作，必须先征得用户明确同意；未经允许不主动推送。
2. **单次提交**：用户要求提交时，将工作区的所有相关改动合并为**一次**提交，不拆分成多个 commit。

## 代码风格

3. **尽量不使用 lambda 表达式**：新增代码优先使用成员槽、具名函数；仅在确有必要的场景才使用 lambda。
4. **遵循项目既有代码风格**：包括 Doxygen 风格注释、`const` 正确性、Qt 习惯用法（信号/槽连接、对象所有权、线程模型）等，保持与现有代码一致。
